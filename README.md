# Employee Management System

## Project Overview

Employee Management System is a web-based application designed
to manage employee information, departments, attendance, salary,
performance and reports.

## Technologies Used

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server/MySQL
- JWT Authentication
- Swagger

### Frontend
- Angular
- TypeScript
- HTML
- CSS

## Main Features

- User Registration and Login
- Authentication and Authorization
- Employee Management
- Department Management
- Attendance Management
- Salary Management
- Performance Management
- Reports
- PDF/Excel Export
